## DreamCandies File Tool

This project is used as a POC migration tools for csv files by DreamCandies. The idea is to select a random sample of 1000 customers from a large dataset and use those codes to extract data related to those customers. The data related to the customers should be extracted from 3 .csv files that the code receives on input: Customer.csv, Invoice.csv and Invoice_item.csv. Since those example files were not given I generated a random dataset for those files according to the description in the assignment text. The test datasets can be found in the Testing folder.
